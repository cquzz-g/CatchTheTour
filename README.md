# CatchTheTour

Учебный проект по анализу данных и разработке на Python — сервис подбора горящих и авторских туров (включая направления выходного дня в Осетию, поездки в Абхазию из Уфы и зарубежные курорты).

## Структура репозитория

* `tours_data.csv` — сгенерированный датасет из 187 предложений туров с параметрами: направление, длительность, звёздность отеля, тип питания, итоговая стоимость, сезон и оценка пользователей.
* `analysis.ipynb` — первичный анализ данных в `pandas` и визуализация закономерностей в `matplotlib` (сравнение цен по направлениям, звёздности отелей и сезонам).
